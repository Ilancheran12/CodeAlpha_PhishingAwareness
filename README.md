

\# CodeAlpha Phishing Awareness Training



\## Project Overview

This project is developed as part of the CodeAlpha Cyber Security Internship.



The main objective is to educate users about phishing attacks and help them stay safe online.



\## Features



\- Introduction to Phishing Attacks

\- Types of Phishing

\- Phishing Email Examples

\- Online Safety Tips

\- Interactive Quiz

\- Automatic Quiz Score Calculation

\- Restart Quiz Option

\- Responsive Website Design



\## Technologies Used



\- HTML

\- CSS

\- JavaScript

1\. Download or clone this repository.
